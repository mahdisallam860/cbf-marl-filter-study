## McNemar sample sizes: scenarios with explicit assumptions

Two-sided exact McNemar test, power 0.8; n = pairs per test (closed form, Connor 1987 / exact test simulated, 4,000 replicates). Both directions of change are assumptions, not estimates. 'inf' = no net effect (p10 = p01): no number of pairs gives power. If the nine policies each get a disjoint layout set and their pairs are pooled in one test per density (protocol draft, section 6), the layouts per policy are n / 9 (column `n_per_policy_9_disjoint` in `sample_size_scenarios.csv`).

Filter-off facts that bound the scenarios (min-max over the nine policies, validation): K = 1: collision 3.0-11.5%, GOAL 17.0-82.0%; K = 2: collision 10.5-26.0%, GOAL 48.5-79.5%; K = 3: collision 27.5-63.0%, GOAL 14.0-58.0%. A scenario needs p10 <= P(collision, filter off) and p_gain <= 1 - P(GOAL, filter off); these bounds are the only use of filter-off data here.
